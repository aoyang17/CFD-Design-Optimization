Data for data-based CRM wing analysis

1. SampleData

135,108 training data and 47,967 validating data with 60 parameters (Mach, Altitude, AoA, 7 twists, 50 wing modes).
Each row has 63 values: 60 parameters and CL, CD, CM.

2. NNmodels

An example to train NN prediction models using the data.

3. wingmodes

An example to set up the wing modes to pyGeo.

4. tecView

An example to show the optimized results in Tecplot.
