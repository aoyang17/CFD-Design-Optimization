# Tecplot visualization

This directory contains the editable Tecplot assets migrated from `Tecplot_wing_visualization_templates`:

- `layouts/` for view definitions;
- `macros/` for Tecplot automation;
- `styles/` for reusable display settings;
- `scripts/` for figure post-processing;
- `docs/` for inventory and local-asset guidance.

CFD data, complete original archives, rendered images, PDFs, and frame sequences are local-only assets. Follow the repository-level asset policy before creating new visualization data or outputs.
